# Security Policy

## Scope
AuthMaster is educational. The sample API is not advertised as a production identity service.

## Reporting a concern
Do not publish passwords, tokens, private keys, personal data, or weaponizable exploit details in a public issue. Use GitHub's private vulnerability reporting feature if enabled, or contact the maintainer privately through a channel listed on their GitHub profile.

Include the affected path/commit, impact, prerequisites, and safe reproduction using synthetic data. Allow time for triage before public disclosure.

## Expectations
No security response-time guarantee is implied. Do not test systems you do not own or have permission to assess. Rotate any secret that may have been exposed.
