# Contributing to AuthMaster

AuthMaster is a learning repository. Contributions should improve conceptual accuracy, safety, testability, and teachability.

## Contribution standards
- Explain concepts in plain language before introducing jargon.
- Distinguish authentication from authorization.
- Include assumptions, trade-offs, and failure cases.
- Prefer official standards and maintained documentation.
- Do not add real credentials, tokens, private keys, or personal data.
- Do not present a teaching lab as production-ready.
- Include a test plan for code changes and examples for conceptual changes.
- Keep examples small enough to teach but explicit about missing production controls.

## Suggested workflow
1. Open an issue describing the learning gap or bug.
2. Make a focused change.
3. Run tests and inspect rendered Markdown.
4. Check links and code snippets.
5. Explain security implications and residual risks in the pull request.

## Reporting a vulnerability
Do not publish exploitable details or real secrets in an issue. Use private vulnerability reporting if enabled or contact the maintainer privately.
